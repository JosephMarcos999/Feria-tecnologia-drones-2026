# Feria Tecnológica de Drones 2026

Sitio web estático informativo y responsive para difundir la **Feria Tecnológica de Drones**, un evento abierto al público con exposiciones, talleres y charlas sobre innovación en drones.

## Descripción del proyecto
Web creada con Bootstrap 5 para presentar el evento de forma clara y atractiva, mostrando información esencial (qué es, cuándo, dónde) y programa. Totalmente responsive en móvil, tablet y ordenador.

## Secciones usadas y columnas Bootstrap
- Hero: full-width.
- Sección 1 (Información): row con 2 columnas .
- Sección 2 (Programa): row con 3 columnas en desktop , 1 en móvil.

## Componentes Bootstrap usados
- Navbar (fixed-top, dark, responsive)
- Cards (para programa)
- Botones (btn-primary, btn-lg)

## Commits y mejoras
- Primera parte: Estructura básica HTML con Navbar, Hero y Footer.
- Segunda parte: Secciones de información y programa con contenedores y cards.
- Tercera parte: Ajustes visuales con CSS , imágenes y capturas.

## Mayor dificultad y solución
Dificultad: Subir la rama desarrollo y sincronizar con main en un repositorio vacío.  
Solución: Usar `git push --set-upstream origin desarrollo` para crear la rama remota por primera vez
